# Hospital-Readmission-Analysis
Healthcare analytics project using Excel to analyze hospital readmissions and identify factors affecting patient outcomes.
## Dashboard

![Dashboard](dashboard.png.emf)

## Project Overview

This project analyzes hospital readmission patterns using Excel. The objective is to identify factors associated with higher readmission rates and provide data-driven recommendations to improve patient care and reduce healthcare costs.

## Business Problem

Hospital administrators are concerned about increasing readmission rates, which negatively affect patient outcomes and increase operational costs. This analysis explores demographic, clinical, and operational factors influencing readmissions.

## Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* Dashboard Design
* Correlation Analysis

## Dataset

Hospital Administration Dataset (101,766 patient encounters)

## Key Questions Answered

1. Readmission rates by age group
2. Length of stay by medical specialty
3. Emergency visits and readmission relationship
4. Diabetes and readmission patterns
5. Medication changes and readmissions
6. Race and gender disparities
7. Comorbidity impact
8. Medication impact on length of stay

## Key Findings

* Elderly patients have the highest readmission risk.
* Medication volume shows a moderate positive relationship with length of stay.
* Patients with multiple diagnoses are more likely to be readmitted.
* Readmission rates vary across demographic groups.

## Recommendations

* Strengthen post-discharge follow-up for elderly patients.
* Introduce risk scoring for high-comorbidity patients.
* Improve medication review processes.
* Develop targeted intervention programs for high-risk demographics.
